# OpenCloud

OpenCloud is typed Luau clients for Roblox's Open Cloud APIs. Each Open Cloud service is its own package with one function per operation and a Luau type for every request and response, so the type checker sees your Open Cloud calls the same way it sees the rest of your code.

The clients are generated by [OpenApiLuau](https://github.com/flipbook-labs/openapi-luau) from the OpenAPI spec Roblox publishes, and they run on Lute. A weekly job regenerates them when Roblox updates the spec.

## Install

Add the services you call, plus the Lute transport the clients send requests through, to your `pkg.luau`, then run `lute pkg install --vendor`:

```luau
dependencies = {
	["luau-execution"] = {
		sourceKind = "github",
		source = "https://github.com/flipbook-labs/open-cloud",
		target = "workspace/luau-execution",
		rev = "v0.2.0",
	},
	["openapi-lute-transport"] = {
		sourceKind = "github",
		source = "https://github.com/flipbook-labs/openapi-luau",
		target = "workspace/openapi-lute-transport",
		rev = "v0.1.0",
	},
},
```

The packages so far are `assets`, `luau-execution`, and `places`, named after each service's page in Roblox's [Open Cloud reference](https://create.roblox.com/docs/cloud/reference).

## Use

Create a client with your API key, then call an operation. This runs a script in a place:

```luau
local process = require("@std/process")

local LuauExecution = require("@lpm/luau-execution@v0.2.0")
local OpenApiLuteTransport = require("@lpm/openapi-lute-transport@v0.1.0")
local OpenApiRuntime = require("@lpm/openapi-runtime@v0.1.0")

local client = OpenApiRuntime.createClient({
	baseUrl = "https://apis.roblox.com",
	transport = OpenApiLuteTransport,
	headers = {
		["x-api-key"] = process.env.ROBLOX_API_KEY,
	},
})

local task = LuauExecution.createLuauExecutionSessionTaskUsingUniverses(client, {
	universe_id = "1234567890",
	place_id = "9876543210",
	body = {
		script = "return game.PlaceId",
	},
})

print(task.path, task.state)
```

Each function's doc comment links to the operation in Roblox's reference. OpenApiLuau's README explains how functions are named and how errors and large numbers behave.
